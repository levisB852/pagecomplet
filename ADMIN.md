# Panel simple de contenido

El archivo `admin.html` permite editar contenido sin tocar directamente el HTML.

## Como funciona

1. Abre `admin.html`.
2. Elige `Videos` o `Eventos`.
3. Edita, agrega o elimina items.
4. Copia o descarga el JSON.
5. Reemplaza el archivo correspondiente:
   - `data/videos.json`
   - `data/eventos.json`
6. Sube los cambios a GitHub.

Este panel no guarda directamente en GitHub porque el sitio es estatico y no tiene login/backend. Mas adelante se puede conectar a un CMS con usuario y contrasena.
