Administrar el sitio

  1. Selecciona una sección en el menú del panel.
  2. Abre el contenido que quieres editar o agrega uno nuevo.
  3. Usa Publicar en la página para mostrarlo; apágalo para conservarlo como borrador.
  4. Las fechas de publicación y retiro son opcionales y permiten programar contenido.
  5. Presiona Guardar y espera unos minutos mientras Netlify actualiza el sitio.

En las listas puedes arrastrar los elementos para cambiar el orden. Antes de eliminar una imagen, comprueba que seleccionaste la correcta.
